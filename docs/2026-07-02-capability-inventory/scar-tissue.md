# SCAR TISSUE — Inventaris Workaround, Magic Number, & Platform Quirk

**Tanggal:** 2026-07-02 · **Cakupan:** plugins/telegram, plugins/pty-controller (+wrapper/src), plugins/agent-bus, plugins/bot-conduct, plugins/daily-report · **Konteks insiden:** docs/2026-06-07-design-decision-batch-injection-and-neighbor-autonomy.md, docs/2026-06-06-plugin-technical-review.md

Dokumen ini adalah katalog **pengetahuan yang dibayar mahal secara empiris** — setiap delay, retry, fallback, dan guard di codebase lahir dari kegagalan nyata (keystroke tertelan, token 409, rename hilang, buffer ConPTY drop). Untuk rewrite harness: **versi baru boleh mengganti SOLUSINYA, tapi wajib tahu MASALAHNYA ada.** Setiap item adalah decision point: putuskan apakah masalahnya masih relevan di desain baru, dan kalau ya, uji ulang solusinya (angka empiris TIDAK boleh diasumsikan portabel ke mekanisme baru). Nomor baris merujuk snapshot 2026-07-02.

## Windows

- [ ] **SCAR-019** **ConPTY input-buffer head-drop**: satu write besar satu-baris-panjang ke input TUI CC di Windows meluapkan buffer — stream membuang karakter TERTUA (kepala pesan) dan menyimpan ekornya, jadi prompt panjang tiba terpotong tinggal ekor. Solusi: tulis per-chunk dengan jeda (SCAR-007). Ini failure mode paling senyap di seluruh sistem — versi baru WAJIB punya test truncation di Windows — `plugins/pty-controller/wrapper/src/prompt-inject.ts:17-29`, `plugins/pty-controller/wrapper/src/wrapper.ts:245-253`
- [ ] **SCAR-020** Chunk split pakai **code point** (`Array.from`), bukan unit UTF-16 — batas chunk tidak boleh membelah surrogate pair (pesan berisi emoji; surrogate terbelah merusak stream). `join('')` harus selalu merekonstruksi input — `plugins/pty-controller/wrapper/src/prompt-inject.ts:26-35`
- [ ] **SCAR-021** `fs.watch` di Windows tidak andal: (a) bisa melewatkan event create pada rapid create+delete; (b) watch single-file drop saat editor menulis atomic-rename (inode swap). Mitigasi tiga lapis: watch DIREKTORI (bukan file), defer 50ms, plus interval sweep. Post-/clear malah full-polling: "fs.watch's create-event coverage on Windows is historically flaky and this path needs to be reliable" — `plugins/pty-controller/wrapper/src/wrapper.ts:825-828,1215-1240`, `plugins/telegram/server.ts:2059-2071,2117-2140`
- [ ] **SCAR-022** `renameSync` di Windows bisa gagal **EPERM/EBUSY** karena antivirus / Search Indexer memegang file tujuan sesaat (window <100ms). Solusi: retry progresif 50/100/150/200ms (total <500ms, 5 attempt) khusus dua kode error itu; error lain tetap dilempar — `plugins/pty-controller/wrapper/src/wrapper.ts:466-492`
- [ ] **SCAR-023** Kegagalan rename registry di heartbeat di-guard terpisah supaya exception dari timer callback TIDAK membunuh proses wrapper — `plugins/pty-controller/wrapper/src/wrapper.ts:778-786`
- [ ] **SCAR-024** `chmodSync` adalah **no-op senyap di Windows** — proteksi 0600 pada `.env` (token bot) dan `messages.db` tidak berlaku; satu warning eksplisit dipancarkan saat boot alih-alih pura-pura berhasil. Versi baru: putuskan strategi ACL Windows — `plugins/telegram/server.ts:57-69,103-111`
- [ ] **SCAR-025** Spawn di Windows harus lewat `cmd.exe /c` karena `claude` adalah shim `.cmd`; di Unix harus lewat **login shell interaktif** (`-l -i -c`) agar `claude` resolve lewat PATH/rc-file user — skip shell memicu `posix_spawnp ENOENT` untuk shim npm — `plugins/pty-controller/wrapper/src/wrapper.ts:368-369,553-566`, `plugins/pty-controller/wrapper/src/interactive.ts:23-27`
- [ ] **SCAR-026** Kelas bug **CRLF/BOM** (dari docs, sebagian belum difix di kode): (a) parser `.env` regex `^(\w+)=(.*)$` TIDAK membuang `\r` — `.env` hasil Notepad/`Out-File` → token bertrailing-CR → grammy 404 permanen tanpa petunjuk (backlog LOSS-5); (b) tidak ada `.gitattributes` → skrip bash bisa ter-checkout CRLF dan mati; (c) PowerShell 5.1 `-Encoding utf8` menulis BOM yang merusak `plugin.json` ("corrupt manifest", insiden bot-06 2026-06-06). Versi baru wajib trim `\r`, ship `.gitattributes`, dan larang Set-Content untuk file JSON — `plugins/telegram/server.ts:71-80`, insiden: `docs/2026-07-02-improvement-backlog.md` LOSS-5, `docs/agent-playbook-snapshot-2026-06-07.md:35-37`
- [ ] **SCAR-027** Semua tulisan state pakai pola atomic `tmp.<pid>` + rename, dan setiap konsumen sweep men-skip file mengandung `.tmp.` (file mid-write). Dua sisi kontrak ini harus pindah BERSAMA ke desain baru — `plugins/pty-controller/ipc.ts:60-63`, `plugins/pty-controller/wrapper/src/wrapper.ts:1233-1234`, `plugins/telegram/server.ts:2121`
- [ ] **SCAR-028** Probe PID `process.kill(pid, 0)`: `ESRCH` = mati, `EPERM` = hidup-tapi-user-lain, error lain (cross-host mount) = percayai heartbeat. Catatan terbuka: **PID reuse** tidak ditangani — pid file basi yang ke-reuse proses lain bisa memberi false-alive (pty) atau salah-SIGTERM proses tak bersalah (telegram takeover, SCAR-064) — `plugins/pty-controller/ipc.ts:228-249`

## Lifecycle proses
